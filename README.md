- Laravel 9

- Git and Git Bash

## Installation
1. Clone this repository.
2. Open the project folder.
3. Run `composer install`.
4. Copy `.env.example` to `.env`.
5. Run `php artisan key:generate`.
6. Create the database `laravel_request_system_db`.
7. Configure the local database connection in `.env`.
8. Run `php artisan migrate`.
9. Run `php artisan serve`.

## Database Setup
Database name: laravel_request_system_db

Recreate the database tables using the included migrations.
A MySQL SQL export is not required.

## Running the Project
Run `php artisan serve`.

Open http://127.0.0.1:8000 in your browser.
